# Meu Diário Acadêmico

Aplicativo desenvolvido em React Native com Expo para a Atividade 01 da disciplina de Programação para Dispositivos Móveis do IESB.

## Funcionalidades

- Exibe o título "Meu Diário Acadêmico";
- Possui campo para digitar o nome de uma disciplina;
- Possui botão "Adicionar";
- Exibe uma lista de disciplinas.

## Tecnologias utilizadas

- React Native
- Expo
- JavaScript

## Como executar

```bash
npx expo start --web
